# Requirements — reportes

> Feature id: 18 | Sprint 5 | Stories: HU52, HU53, HU54

---

## Reporte de envíos por estado y período

R1. WHEN an authenticated OPERADOR sends a request to `GET /api/v1/reportes/envios` with valid `desde` and `hasta` query parameters THE SYSTEM SHALL return HTTP 200 with a response body containing: total count of shipments per `EstadoEnvio` value and a daily breakdown (count per calendar day) for the given date range.

R2. WHEN the `desde` or `hasta` query parameter is missing THE SYSTEM SHALL return HTTP 422 with a validation error indicating which parameter is absent.

R3. WHEN the `desde` date is later than the `hasta` date THE SYSTEM SHALL return HTTP 422 with an error message indicating the invalid date range.

R4. WHEN the date range contains no shipments THE SYSTEM SHALL return HTTP 200 with empty arrays for the daily breakdown and zero counts for all states.

---

## Exportación CSV de envíos

R5. WHEN an authenticated OPERADOR sends a request to `GET /api/v1/reportes/envios/export` with valid `desde` and `hasta` query parameters THE SYSTEM SHALL return a CSV file (Content-Type: `text/csv`) as a download attachment containing one row per shipment in the period with the columns: `codigoSeguimiento`, `estado`, `remitente`, `destinatario`, `direccionDestino`, `createdAt`.

R6. WHEN the `desde` or `hasta` query parameter is missing on the export endpoint THE SYSTEM SHALL return HTTP 422 with a validation error.

R7. WHEN the date range contains no shipments on the export endpoint THE SYSTEM SHALL return a CSV file containing only the header row and no data rows.

---

## Reporte de ranking de repartidores

R8. WHEN an authenticated OPERADOR sends a request to `GET /api/v1/reportes/repartidores` THE SYSTEM SHALL return HTTP 200 with an array of repartidor ranking entries, each containing: `id`, `nombre`, `totalEntregados` (shipments with state ENTREGADO), and `totalFallidos` (shipments with state FALLIDO or CANCELADO), ordered descending by `totalEntregados`.

R9. WHEN there are repartidores with zero deliveries THE SYSTEM SHALL include them in the ranking with `totalEntregados: 0` and `totalFallidos: 0`.

---

## Autenticación y autorización

R10. WHEN a request reaches any `/api/v1/reportes/*` endpoint without a valid JWT Bearer token THE SYSTEM SHALL return HTTP 401 with `{ error: "UNAUTHORIZED", statusCode: 401 }`.

R11. WHEN a request reaches any `/api/v1/reportes/*` endpoint with a valid JWT whose role is not OPERADOR THE SYSTEM SHALL return HTTP 403 with `{ error: "FORBIDDEN", statusCode: 403 }`.

---

## Pantalla de Reportes (frontend)

R12. WHEN the OPERADOR navigates to `/reportes` THE SYSTEM SHALL display a page titled "Reportes" containing: a date-range selector (desde/hasta), a bar chart of shipments per day, a state breakdown summary, and a ranking table of repartidores.

R13. WHEN the OPERADOR changes the date-range selection THE SYSTEM SHALL re-fetch and re-render the envíos report data without requiring a full page reload.

R14. WHEN the envíos report data is loading THE SYSTEM SHALL display a loading skeleton in place of the chart and table.

R15. WHEN the OPERADOR clicks the "Exportar CSV" button THE SYSTEM SHALL trigger a file download of the CSV generated by the export endpoint for the currently selected date range.

R16. WHEN the export is triggered THE SYSTEM SHALL use the same `desde` and `hasta` values currently selected in the date-range selector.
